Trust boundary · topic-page-generator · 3 / 5

Schema validation is the trust boundary between the LLM and the editor

Every fact on the page must trace to a real source. That's not a warning — it's a set-membership check at the extraction boundary. A section either parses with all claims cited, or it doesn't ship.

Research · topic-page-generator · 4 / 5

Research — the per-section evaluator loop

Each section self-corrects: the judge names what's missing, and the next query targets that gap — bounded, so a thin pool fails fast instead of looping forever.

Generalization · topic-page-generator · 1 / 5

Generalization: anchor on reader needs, not event types

Don't chase the open set of event types — it's infinite and goes stale the moment a new archetype appears. Anchor on the closed set of reader needs: the questions journalism has answered for a century.
